# GitHub Repository Finder

A full-stack application using React + FastAPI.

## Features
- Search GitHub users
- Fetch repositories using GitHub API
- Loading state
- Error handling

## Tech Stack
- React (Vite)
- FastAPI
- GitHub REST API

## Run Frontend

cd frontend
npm install
npm run dev

## Run Backend

cd backend
source .venv/bin/activate
python -m uvicorn main:app --reload
